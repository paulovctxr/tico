# tico-pousada — Vercel

Site estático em HTML, CSS e JavaScript. Sem banco de dados ou variáveis de ambiente.

## Publicar pelo GitHub
1. Crie um repositório no GitHub para esta pousada.
2. Envie o conteúdo DESTA pasta (incluindo assets e vercel.json) para a raiz do repositório.
3. Na Vercel, abra Add New → Project e importe o repositório.
4. Use Framework Preset: Other; Root Directory: ./; Build Command vazio; Output Directory: .; Install Command vazio.
5. Clique Deploy.

Se colocar todas as pousadas em um único repositório, crie um projeto Vercel para cada pousada e selecione esta pasta como Root Directory.

## Alternativa pelo terminal
Com Node.js instalado, abra um terminal nesta pasta e execute:

```
npx vercel login
npx vercel --prod
```

Escolha sua conta, crie um novo projeto e use a pasta atual.

O WhatsApp só abre quando o visitante clica; não há envio automático. Confirme contatos e informações com a propriedade antes de usar o site comercialmente.
